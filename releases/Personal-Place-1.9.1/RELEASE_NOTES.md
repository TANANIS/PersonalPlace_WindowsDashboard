# Personal Place v1.9.1

- 完成 Personal Place 2.0 Stage 5 視覺系統遷移與 runtime recovery。
- 統一 Dashboard 捷徑與內建小工具高度，修復混合卡片內容排版。
- 補齊整理模式選取操作列、卡片狀態與拖曳相關視覺。
- 搜尋預設收斂，聚焦時才顯示範圍選項；頁首操作降低視覺干擾。
- 行事曆事件詳情改為清楚的資訊分組，Activity 今日時間軸改善文字間距與辨識度。
- Today、Todo、Focus、Calendar、Activity、設定與導覽元件採用一致的 Stage 5 視覺契約。
- 不變更資料 schema、備份格式、ActivityWatch 查詢語意或本機優先隱私邊界。

目前公開下載只提供 portable；installer 因 Windows Defender ML detection 與簽章限制不公開。portable EXE 未使用受信任的 Authenticode 憑證簽章。
